How the pulse drive would work on Val (not built)

  • The wire's strength (0 to 1, as now) sets the beat rate: none in the dark with a + wire, up to the top rate in full light.
  • Each beat is the same push. Push and glide ramps the wheel up fast and lets it run down, like a bell's stroke then coast; on and off runs it at one speed for the beat.
  • Average speed = beat rate × one beat's push, so it matches the smooth drive. At the top rate the beats run together.
  • It is only a change in how the speed is sent to the servo (the angle register, over time). The wiring, setup screens and lesson results stay the same.

What to look for

  • Do the two Vals end up in the same place, run after run (each run, both start in the same place, facing the same way)? (They should: same rule, same average. With a + wire both end up resting in the dark; with a − wire, in the light.)
  • Does the pulsing Val read as alive like a jelly, or as stuttering?
  • With a + wire, Val (and the jelly) end up in the dark: more light, more push, so they hurry out of the light and slow to a stop where it is dim. It looks like avoiding the light, though nothing in the wiring knows where the light is.
  • Val is set down facing the other half, as a child would in the lesson. With "any way", many runs end with Val stuck against a wall: set down facing it, Val drives into it and keeps pushing, wherever the light is. That is true of the real robot in a walled tray, so the count keeps those runs apart ("wall").
  • Neither Val can turn: one wheel and fixed feet go straight, with a slight drift. It stops in the dark (with a + wire) or at a wall, and only a hand sets it down facing somewhere new. The jelly can turn a little: that is where it is more than Vehicle 1.
  • Push and glide needs headroom: a beat's peak is about two and a half times the average, so the smooth drive's top speed would have to sit well below the servo's top speed for the two to match. On the robot that means a slower top speed, or beats that can't fully catch up in bright light.
  • A real wheel doesn't coast like a bell in water: when the servo eases off, Val slows at once. The "glide" is the servo slowing on purpose.

The jelly is the imperfect ancient version

  • It follows the same wire as Val: with + it pulses more in the light, so it hurries through the light and lingers in the dark, and gathers there over time, as Val does. With − it gathers in the light.
  • Its pulse rate follows the light, as Val's beats do. It also pulses a little in the dark (jellies have their own rhythm), drifts with the water and turns a little: a real radial animal is not as simple as Vehicle 1.
