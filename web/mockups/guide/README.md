# Guide mock-ups (pages a child and adult read)

Single web pages, made to try the guide's look and order before it is built. Open a
file in a browser; nothing else is needed (fonts load from Google Fonts). Both are also
published as private artifacts for the owner. **Mock-ups, not the guide itself:** all
story text and the title are placeholders.
