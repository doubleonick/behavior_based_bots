What silences a memory cell

A mock-up, not firmware. One module with three wires. Port A's wire has a memory cell: once light switches it on, it holds itself on. The new screen chooses another wire that switches the memory off. Then try it: switch the memory on, take the light away, and see what turns it off. Only two dots show on the matrix: the memory's own wire (cyan) and the one that switches it off (red).

This module

  • Port A: Light Unit, + wire, with a memory cell (on the wire, strongest self-weight). Its dot is on the left of the top row.
  • Port B: Color Unit, feeling magenta, + wire. Its dot is in the middle.
  • Port C: Key, + wire. Its dot is on the right.
